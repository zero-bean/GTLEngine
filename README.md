## 01. 프로젝트 설명
### DirectX 11 기반 자체 엔진, Mundi Engine

DirectX 11를 사용하여 Win32 API에서 0줄 코드에서 계속 더하여 만든 3D 자체 엔진입니다.

그래픽스의 기초 원리를 습득했으며, Unreal Engine의 핵심 구조를 직접 구현하여 엔진에 대한 이해도를 갖추었습니다.

- **[팀 빌딩]** 주마다 무작위 3~4인 1팀으로 진행하며, 지난 주차의 결과물 코드 중 하나를 선택하여 엔진을 제작
- **[일정]** 2025.09 ~ 2025.12 약 14주 | 주 6일 10:00 ~ 23:00+ 대면 진행
